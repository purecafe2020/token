关于 Token 日报

Token 日报每天整理国内外大模型 API 的免费额度、限时优惠与新用户试用金，目标是让开发者用最少的时间找到真正能领的额度。

我们怎么做

  • 每天对照官方文档与活动页，确认额度、价格和截止时间是否变化；
  • 每条标注核实等级：已核实官方文档 / 部分核实 / 待核实；
  • 记录限速、有效期、是否绑卡等容易被忽略的坑点。

我们不做什么

不提供账号代注册，不销售额度，也不承诺任何活动长期有效。额度与规则以各平台官方控制台为准。

信息来源

以官方文档与官方活动页为准；商业线索站只用于发现活动，结论必须回到官方页面核实后才会上榜。

这是一个由个人维护的独立站点，与文中提到的任何厂商均无隶属关系。
