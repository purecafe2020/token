免费 GPU 额度怎么选：Colab、Kaggle、AI Studio 对比

2026-11-23 · 每周更新
结论先说：当天就要跑通 Notebook，用 Google Colab；要长期免费跑训练，用 Kaggle；国内网络优先，用百度 AI Studio；正式项目要合规与发票，走华为云 ModelArts 申请。四家都不是「无限免费」，真正的约束是单次时长和配额重置。

为什么免费额度都卡「单次时长」

免费 GPU 的成本是按卡时算的，平台愿意送时长，但不愿意让一个会话长期占卡。所以几乎所有免费额度都做了两件事：限制单次运行时长、闲置一段时间自动断开。理解了这一点，用法就清楚了——把长任务拆成能续跑的短任务，而不是赌会话不断。

Google Colab：最快的上手路径

打开就能用，T4 对 7B 以下的模型微调够用。真正的坑在存储：/content 是临时的，会话一断全部丢失。训练前把数据集放到 Drive 或 Hugging Face，脚本里每次先检查缓存是否存在。Colab 的详细说明

Kaggle：免费额度里最接近「能跑完」的

每周约 30 小时 GPU，单次约 9 小时，P100 16GB。适合把 Colab 上调通的脚本搬过来跑全量。注意它默认没有外网持久存储，输出要保存为 Notebook 产物或数据集，否则会话结束就没了。Kaggle 的详细说明

百度 AI Studio：国内网络的最优解

国内直连速度快，实名后按天发放卡时。适合中文模型微调与教学演示。高峰期需要排队，长任务建议放到夜间；平台对脚本有审计，别跑与学习无关的负载。AI Studio 的详细说明

华为云 ModelArts：申请制，别当救急

它不是自动发放，需要在表单里写清用途与项目背景。适合毕设、企业 PoC 这类能等审批的场景。如果你今天就要跑，别指望它。ModelArts 的详细说明

推荐的组合用法

  1. 本地写代码：用 VS Code 或 Cursor 写训练脚本，靠配置文件控制路径，不依赖某个平台的目录结构。
  2. Colab 调通：先用几百条样本跑通全流程，确认显存和依赖没问题。
  3. Kaggle 跑全量：把脚本搬过去，开 9 小时档，输出存成产物。
  4. 不够再上按需：真要连跑几天，用按秒计费的服务（如 RunPod）比堆免费额度更省心。

三个高频坑

  • 显存对不上：免费档多是 16GB，7B 模型全量微调基本放不下，先算清 batch size 与 LoRA 的显存占用。
  • 没有断点续训：会话一断全部重来。训练循环里每 N 步存一次 checkpoint 到持久存储，是免费额度的必修课。
  • 把免费当生产：免费额度没有 SLA，排队和抢占随时发生。对外提供的服务不要建在免费档上。

FAQ

免费额度需要绑卡吗？

Colab 与 Kaggle 免费档不需要绑卡；Google Cloud 的 $300 赠金需要绑卡，用完会自动扣费，务必设预算告警。

一周 30 小时够训练吗？

够跑中小模型的全量微调与比赛复现，不够长时间预训练。真需要更大算力，按需租比攒额度更现实。

国内还有别的免费 GPU 吗？

阿里云 PAI、腾讯云 Cloud Studio、华为昇腾社区都有试用或活动额度，但多为限时或申请制，见算力栏目的完整清单。
