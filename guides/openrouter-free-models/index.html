OpenRouter 免费模型怎么用：限速、充值与避坑（2026）

2026-11-22 · 已核实：官方文档 · 名单会变动
结论先说：一个 Key 就能调 20+ 个 :free 模型，限制是 20 RPM、每天 50 次；累计充值满 10 美元后，每日上限永久提升到 1000 次。

免费额度规则

项目说明

怎么用（4 步）

  1. 注册 OpenRouter，创建 API Key；
  2. 在模型列表按「免费」筛选，或直接用 openrouter/free 让平台自动选可用模型；
  3. 用 OpenAI SDK，把 base_url 设为 https://openrouter.ai/api/v1；
  4. 给请求加 fallback 链（两三个 :free 模型），避免单个模型 429 就整条任务失败。

四个坑

1. 失败的请求也扣次数

超时、上游 429 都算一次。别写紧密重试循环，用指数退避。

2. 免费名单随时会变

DeepSeek R1、Qwen3 Coder 480B、Llama 3.3 70B 都已从免费名单下架。把模型 ID 写死在代码里，迟早 404。

3. $10 是一次性门槛，不是每月充值

累计充值满 $10 后即使余额花光，1000 次/天的上限也永久保留，不需要续费。

4. 免费模型的数据可能被上游使用

不同提供方策略不同，敏感数据别走免费档。

适合谁

  • 想低成本试多个模型效果的开发者；
  • 做原型、跑低频 Agent 任务的个人项目。

FAQ

50 次/天够干什么？

够日常调试和轻量问答。要做批量任务，建议先充 $10 拿到 1000 次/天，成本约 70 元人民币。

免费模型能商用吗？

多数可以，但要逐一确认上游模型的许可证；部分模型禁止商业用途。

怎么处理 429？

先切 fallback 模型，再退避重试；不要在 1 分钟内反复打同一个模型。
