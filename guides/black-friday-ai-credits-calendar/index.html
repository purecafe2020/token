三个时间坑

1. 同一天截止，实际差 16 小时

七牛按北京时间 11-30 24:00 收；OpenModel 按 UTC，折北京时间 12-01 07:59；HiAPI 按美西 PT，折 12-01 15:59。UTC 与 PT 相差 8 小时，PT 与北京相差 16 小时——只按「11-30」记，会漏掉后两家。

2. 实名与绑卡不能当天完成

七牛要实名，HiAPI 要外币卡，OpenModel 要外币支付。这些环节卡住就是几小时到一天，别在截止当天才做。

3. 返现到账晚于活动结束

HiAPI 的消费返还 12-03 才到账。不影响资格，但会影响你对「到手多少」的判断——先按返还前的余额规划用量。

建议的动手顺序（11-28 起）

  1. 今天先把实名与外币卡弄好，门槛类事项最耗时；
  2. 这周末（11-28～11-30）跑批量任务，别留到最后一个下午；
  3. 充值类只看「本来就会用多少」，为赠额充值大概率是亏的；
  4. 12-01 早上再核对一次，按 PT 的两家还有半天缓冲。

FAQ

黑五之后还有活动吗？

有。百度普惠与 Gemini 锁价都到 12-31，packet.ai 到 12-16，LinkModel 与 Swarms 到 12-02。节日活动结束后，长期额度仍是主线。

充值返赠值得冲吗？

取决于你本来就打算花多少。返赠额度只能用于 API 调用、不可提现，为返赠而充值大概率是亏的。

Google 的 $300 还能跑 Gemini 吗？

11-16 之后注册的账号不行了。官方文档写明 $300 不能用于 Gemini 平台（原 Vertex AI）；此日期前注册的老账号仍可抵扣。
