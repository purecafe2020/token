三个时间坑

1. 时区不一致，最后一天差十几小时

HiAPI 用美西时间（PT），OpenModel 用 UTC，七牛用北京时间。同写「11-30 截止」，实际差出十几小时。按北京时间换算再排计划。

2. 实名与绑卡不能当天完成

七牛要实名，HiAPI 要外币卡，OpenModel 要外币支付。这些环节卡住就是几小时到一天，别在截止当天才做。

3. 返现到账晚于活动结束

HiAPI 的消费返还 12-03 才到账。不影响资格，但会影响你对「到手多少」的判断——先按返还前的余额规划用量。

FAQ

黑五之后还有活动吗？

有。百度普惠与 Gemini 锁价都到 12-31，packet.ai 到 12-16。节日活动结束后，长期额度仍然是主线。

充值返赠值得冲吗？

取决于你本来就打算花多少。返赠额度只能用于 API 调用、不可提现，为返赠而充值大概率是亏的。
