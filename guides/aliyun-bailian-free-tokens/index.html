阿里云百炼 100 万 Token 领取全流程（2026）

2026-11-22 · 已核实：官方文档 · 有效期 90 天
结论先说：首次开通百炼，每个在售文本模型各送 100 万 Token，从开通（或模型发布/申请通过，取较晚者）起算 90 天。不是共享池，是逐模型发放。

额度规则

项目说明
额度每个模型 100 万 Token（Qwen3.8-Flash、Qwen3.7-Flash、MiniMax-M2.5 等）
有效期90 天，到期不补发、不延期
地域仅华北 2（北京）实时推理
不适用Batch 调用、模型微调、部署
其他图像类另有人物实例分割 500 张体验额度

怎么领（4 步）

  1. 注册阿里云并完成实名认证；
  2. 开通「百炼」服务，额度会自动发放，无需申请；
  3. 在控制台创建 API Key，记下 Key；
  4. 在「模型广场」选模型，按 OpenAI 兼容格式调用，base_url 使用百炼的地址。

四个坑

1. 不是「总共 100 万」，是「每个模型 100 万」

换模型会换一套额度，所以多模型横评很划算；但也意味着别把一个模型的额度当成全平台通用。

2. 90 天从「较晚者」起算

开通早、模型上线晚的，从模型发布日算。看不到额度时先查有效期，很可能已过期。

3. 只在华北 2 生效

其他地域调用会走按量计费，账单出来才发现没抵扣，是常见事故。

4. Batch、微调、部署不吃免费额度

想用免费额度跑批量任务，只能走实时推理接口。

适合谁

  • 想横向比较 Qwen 系列不同档位效果的开发者；
  • 短周期原型验证（90 天足够）。

FAQ

多个模型共享 100 万吗？

不共享。每个模型独立 100 万，按模型 ID 分别计算。

到期会直接扣费吗？

额度耗尽或到期后继续调用会产生计费。建议在费用中心设置预算告警。

怎么查剩余额度？

控制台的「资源包 / 额度管理」里能看到每个模型的剩余量与到期日。
