七牛云 Conatus 每天 1 亿 Token 怎么领（2026 黑五）

2026-11-22 · 已核实：部分 · 活动截止 11-30
结论先说：活动期内 qiniu/conatus-free 模型每天免费 1 亿 Token，实名后即可用；单次充值满 100 元提升到每天 10 亿。额度每天 0 点清零，不结转。

怎么领（5 步）

  1. 注册七牛云账号，完成实名认证（个人证件即可）；
  2. 进入控制台的 AI 推理 / 大模型服务，开通对应服务；
  3. 创建 API Key，记下 Key 与调用地址；
  4. 把模型名填为 qiniu/conatus-free，用 OpenAI 兼容格式发起请求；
  5. 在控制台的用量页面确认额度是否到账，再开始跑任务。

三个容易踩的坑

1. 额度不结转，别攒着

每日 0 点清零，1 亿 Token 当天不用就没了。适合白天有批处理任务的人，不适合「先攒着以后用」。

2. 「充值 10 亿」要求单次满 100 元

拆成 5 次 20 元不累计。要提额就一次性充够，充完当天生效，但同样每天清零。

3. 活动截止后会转按量计费

11-30 之后免费模型可能下架或转付费，记得在控制台设置额度告警，避免自动扣费。

适合谁

  • 需要大批量文本处理（摘要、抽取、分类）的个人开发者；
  • 想跑长文档任务的人——Conatus 支持长上下文，一天额度足够处理几十份文档。

不适合：需要稳定 SLA 的生产业务，以及需要多模态（图像/语音）的场景。

FAQ

要绑卡吗？

领免费额度通常只需实名，不强制绑卡；但「充值提额」这一步需要支付方式。

额度用完会自动扣费吗？

取决于是否开通了按量计费。没开通时额度用完直接报错；开通后会转按量。建议先不开通。

支持 OpenAI SDK 吗？

七牛提供 OpenAI 兼容接口，把 base_url 指向它、模型名改成上面的 ID 即可。
