大批量摘要与抽取

七牛 Conatus 每天 1 亿 Token
适合每天几十份长文档；额度不结转，按天排任务量。

多模态内容生成

MiniMax（语音/音乐）+ Cloudflare（图像）
两类免费档各管一种模态，能拼出脚本+配音+配图的完整链路。

代码助手与重构

OpenRouter 免费代码模型 + fallback
免费模型会下架，务必配 2~3 个 fallback；长上下文任务选 1M 模型。

批量翻译与本地化

Qwen Flash + 术语表
长文档分段翻译，用术语表保证一致性；先用 1000 字样本调提示词再批量跑。
来源：组合方案 ↗

会议纪要转写

Groq Whisper + 摘要模型
Whisper 每天 2000 次转写额度，配合摘要能出结构化纪要；注意单文件大小上限。

电商商品描述

Qwen Flash + 模板约束
先固定字段与语气，再批量生成；必须人工抽检，避免夸大宣传。
来源：组合方案 ↗

论文与长文档问答

Gemini / Qwen4-Max（1M 上下文）
一次塞完整篇论文，省去切分与检索；免费档限速严，先小批量试。
