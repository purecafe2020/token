# AI Token 羊毛日报

一个「什么值得买」风格的大模型 API 免费额度 / 优惠看板：先按截止时间排，再按力度排，每条都标注核实等级和坑点。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 看板本体。单文件、内联 CSS/JS、无外部依赖，双击即可打开，断网也能看 |
| `data/deals.json` | 同一份结构化数据（24 条），方便二次加工、接通知或做增量对比 |
| `DEPLOY.md` | Cloudflare Pages 部署、每日自动发布、排错 |
| `ACCESS.md` | 用 Cloudflare Access 给页面加邮箱验证码登录 |
| `MIRROR.md` | 国内镜像方案（腾讯云 CloudBase，免备案默认域名） |
| `mirror.config.json` | 国内镜像开关与环境 ID（默认关闭） |

看板能力：按类型（白嫖 / 限时 / 试用金 / 避坑）、地区（国内 / 海外）筛选，关键词搜索，按截止时间 / 力度 / 平台名排序，剩余天数实时计算（7 天内标红）。

## 每天怎么更新

**默认方式（推荐）**：每天对我说一句「更新今日看板」。我会：

1. 检索国内外平台的最新免费额度、限时活动和充值优惠，优先官方文档与官方活动页；
2. 交叉核实——能对上官方页面的标「已核实官方文档」，只有第三方实测的标「部分核实」；
3. 覆盖 `index.html` 顶部的 `UPDATED` 时间戳与 `DEALS` 数据区，并同步导出 `data/deals.json`。

**无人值守定时**：需要外部定时器（Windows 任务计划 / GitHub Actions）驱动一个可联网的 Agent 会话，本目录目前没有配置。如果需要「不打开会话也自动更新」，告诉我，我再补一套定时方案（含失败重试与变更对比）。

## 收录标准

每条必须同时满足：

- 有**可复现的领取入口**（能点进去、能注册、能拿到额度）；
- 有**可追溯的官方来源**（官方文档 / 官方活动页，而不是二手博客的一句话）；
- 写清**坑点**：限速、有效期、是否绑卡、是否按模型计算、免费层数据是否用于训练。

分四类：

- **白嫖**：长期有效的免费额度或永久免费模型；
- **限时**：有明确截止日的活动、促销、锁价窗口；
- **试用金**：新用户赠金 / 试用 credit，通常有使用期限；
- **避坑**：已下线、已缩水、或网传但与官方不符的信息——保留下来专门用来识别过期教程。

## 核实等级

| 标记 | 含义 |
|---|---|
| 已核实官方文档 | 关键数字（额度、价格、日期、限速）能在官方页面直接找到 |
| 部分核实 | 官方入口真实存在，但额度数字来自第三方实测或历史活动页 |
| 待核实 | 入口真实，具体数字请以控制台为准 |

## 注意事项

- 免费额度普遍限速（RPM/RPD）、限并发，且**免费层数据可能被用于模型改进**，不要传客户数据、不要跑生产。
- 官方随时可能调额、下线模型或结束活动；领取前请以控制台实际显示为准。
- 需外币卡的试用金（Google Cloud / Azure 等）务必先设预算提醒、关闭自动升级付费，避免赠金用完后直接扣卡。

## 数据字段

`id` `type` `region` `hot` `platform` `title` `desc` `value` `valueNote` `deadline` `deadlineNote` `link` `linkText` `verify` `tags` `tip`

`deadline` 为 `YYYY-MM-DD` 或 `null`（相对期限时用 `deadlineNote` 说明）。
